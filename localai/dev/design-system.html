"How we estimate this" + footnotes

How we estimate this

Decode is bandwidth-bound: every token streams the model's weights (plus each layer's KV-cache read) through memory. t_token = Σ_layers (layerBytes / BW_of_layer) ÷ η_decode

  • η_decode = 0.85 — one global constant calibrated against five real-world anchors in Phase 2.
  • KV-cache reads are included in layerBytes at the current context length (owner-approved, P2 sign-off).
  • Labeled assumption: multi-GPU bandwidth factors for 1× / 2× / 4× → 1 / 1.75 / 3.2.

The M4 Pro's unified memory runs at 273 GB/s[S2], while the RX 9070 XT hits 644.6 GB/s[S4] — that gap is why offload hurts.

  1. Apple MacBook Pro (M4 Pro) tech specs — memory bandwidth 273 GB/s.
  2. TechPowerUp GPU database — Radeon RX 9070 XT, 644.6 GB/s GDDR6.
  3. Artificial Analysis — GPT-5 family benchmarks (as of Aug 2026).
