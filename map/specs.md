## Work Desktop
AMD Ryzen 7 5700X
8GB Gigabyte RTX 3070
2X 512GB NVME, 1X 512GB SATA SSD
Case: Jonsbo D32 Pro
48GB Corsair Vengeance LPX (32GB DDR4-3000 + 16GB DDR4-3200, machine set at 2833MT/s)
Cooler Master MWE Gold V2 750W

The first version was built to handle video editing at work and made heavy use of older parts from prior builds. I quickly added more memory and this machine began to be used for 3D modeling far more often than video editing. It's connected to a KVM switch which and the screen is mirrored on a 27" 4K monitor at my desk and 2 large displays in the classroom.
