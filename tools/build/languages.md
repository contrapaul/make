# Programming Languages Reference Table — For Your Educational Website

Below is a broad catalogue you can trim down. I've grouped the languages roughly by how a beginner would encounter them, and I've written every cell in plain language so it doubles as copy you can adapt for your pages. The "Demo Idea" column is meant to give you a concrete, in-page interactive or visual example you could build without needing a full IDE.

---

## The Table

| # | Language | Type / Category | What It Actually Does (plain language) | Typical Real-World Applications | Demo / Example Idea for the Page | Key Notes (History, Difficulty, Audience Fit) | Suggested Reference Links |
|---|----------|----------------|--------------------------------------|-------------------------------|----------------------------------|----------------------------------------------|---------------------------|
| 1 | **HTML** | Markup Language | Tells the browser *what* is on a page: headings, paragraphs, images, links, tables. It is not logic; it is structure. | Every single website on the internet. Email templates. App store descriptions. | A side-by-side "code → rendered page" viewer. Let students click a word in the code and watch the matching element highlight on the preview. | Created by Tim Berners-Lee, 1991, at CERN. **Not Turing-complete** — worth explaining so students understand the difference between markup and programming. Easiest entry point. | [MDN HTML Guide](https://developer.mozilla.org/en-US/docs/Web/HTML) · [W3Schools HTML](https://www.w3schools.com/html/) |
| 2 | **CSS** | Style Language | Tells the browser *how it looks*: colours, fonts, spacing, layout, animations. | Web design. Responsive layouts (phone vs. desktop). Print stylesheets. UI theming. | A "style slider" panel: change a few CSS properties (border-radius, colour, font-size) with dropdowns and watch a sample card update live. | First proposed 1994, standardised 1996. Like HTML, not a programming language in the strict sense. Pairs inseparably with HTML. | [MDN CSS Guide](https://developer.mozilla.org/en-US/docs/Web/CSS) · [CSS-Tricks Almanac](https://css-tricks.com/almanac/) |
| 3 | **JavaScript** | General-Purpose / Web | Adds *behaviour and logic* to web pages: click handlers, form validation, animations, fetching data. Runs in the browser (and now on servers via Node.js). | Interactive websites, web apps (Gmail, Spotify, Netflix UI), browser games, server backends, mobile apps (React Native). | A tiny "whack-a-mole" game or a colour-changing button with a live code editor (embed CodePen or JSFiddle). Show a real page element updating 60 frames/sec. | Created in **10 days** by Brendan Eich, 1995, at Netscape. Renamed from "LiveScript" to "JavaScript" as a marketing nod to Java (they are unrelated). The single most in-demand language for web work. | [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) · [javascript.info](https://javascript.info/) |
| 4 | **TypeScript** | General-Purpose / Web (JS superset) | JavaScript *with rules*. You write JS, but the language checks your types (number vs. string, etc.) before the code runs, catching bugs early. | Large-scale web apps (Microsoft, Google, Slack use it). Any project where "oops, that was a string not a number" would crash production. | Show the same small snippet in plain JS (silent bug) vs. TypeScript (compiler highlights the error). Great "aha" moment. | Released by Microsoft, 2012. Maintained by Anders Hejlsberg (also designed C# and Delphi). Best introduced *after* JavaScript so the "why" is clear. | [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) |
| 5 | **Python** | General-Purpose | A do-everything language prized for reading almost like English. Handles scripting, data analysis, AI, web backends, automation. | Data science (Pandas, NumPy), machine learning (PyTorch, scikit-learn), web backends (Django, Flask), school curricula, DevOps scripts, game prototypes (Pygame). | An auto-running cell: a 5-line script that reads a list of student grades and prints the average + a tiny text bar chart. Let students tweak the numbers and re-run. | Created by Guido van Rossum, 1991 (named after *Monty Python*, not the snake). The default first language in most AP CS / IB CS courses today. Extremely readable → ideal for your audience. | [python.org Tutorial](https://docs.python.org/3/tutorial/) · [Real Python](https://realpython.com/) · [Automate the Boring Stuff (free book)](https://automatetheboringstuff.com/) |
| 6 | **Java** | General-Purpose / OOP | A "write once, run anywhere" language compiled to bytecode that runs on the Java Virtual Machine. Strongly object-oriented. | Android apps (historically), enterprise backends (banks, insurance), Apache Hadoop/Spark, Minecraft (original), large-scale school projects. | A small class hierarchy (e.g., `Animal` → `Dog`, `Cat`) with an override of `speak()`. Show the output. Reinforces OOP vocabulary your students will meet in AP CS. | Created by James Gosling at Sun Microsystems, 1995. Owned by Oracle since 2010. AP Computer Science A has used Java as its exam language since 2003 → **directly relevant to your high-school audience.** | [Oracle Java Tutorials](https://docs.oracle.com/javase/tutorial/) · [Codecademy Java](https://www.codecademy.com/learn/learn-java) |
| 7 | **C** | Systems / Procedural | A low-level language that talks close to the hardware. Minimal built-in features; you manage memory yourself. | Operating-system kernels (Linux, Windows core), embedded systems (car ECUs, microwaves), compilers, IoT firmware. | Show a 15-line C program that reads a string and reverses it, *and* a diagram of how the program sits between the code and the CPU (compile → machine code). Contrast with Python doing the same in 1 line. | Created by Dennis Ritchie at Bell Labs, 1972, to write Unix. The ancestor of C++, Java, C#, JavaScript, and many more. Harder, but understanding it makes every other language feel safer. | [Learn-C.org](https://www.learn-c.org/) · [CS50 (Harvard, free)](https://cs50.harvard.edu/x/) |
| 8 | **C++** | Systems / General / OOP | C with object-oriented features, templates, and a massive standard library. You still manage memory, but get more abstraction. | Game engines (Unreal, parts of Unity), browsers (Chrome, Firefox rendering), high-frequency trading, robotics, Photoshop core. | A short class that wraps a "GamePiece" with position and move logic. Emphasise how it's the language behind *Minecraft* (Bedrock) and most AAA games. | Also by Bjarne Stroustrup, Bell Labs, 1979–85 ("C with Classes"). Steeper learning curve than Python/Java. Best as a "how the software you *use* is built" page. | [cppreference.com](https://en.cppreference.com/w/) · [LearnCPP.com](https://www.learncpp.com/) |
| 9 | **C#** | General-Purpose / OOP | Microsoft's answer to Java. Runs on the .NET framework. Clean syntax, strong tooling (Visual Studio). | Windows desktop apps, Xbox / Unity game development, web backends (ASP.NET), enterprise software. | A 10-line Unity-flavoured snippet: a `MovePlayer()` method that reads arrow-key input. Very visual for students who've played Unity-built games. | Designed by Anders Hejlsberg, released 2000. The "pound" sign is a musical sharp, not the hash symbol. If your school teaches game design or uses Unity, this is a must-include. | [Microsoft C# Guide](https://learn.microsoft.com/en-us/dotnet/csharp/) · [Unity Learn](https://learn.unity.com/) |
| 10 | **SQL** | Query Language | Talks to a *database*. You ask questions in plain-English-ish sentences: "Give me every student whose GPA > 3.5, sorted by name." | Web apps behind the scenes (user accounts, product catalogues), data reporting, business analytics, any app with stored records. | An interactive mini-table (e.g., 8 fictional students). Let students click SELECT / WHERE / ORDER BY blocks to build a query and see rows highlight. No install needed. | Developed at IBM, early 1970s, by Donald Chamberlin and Raymond Boyce. Technically a *declarative* language (you say *what*, not *how*). Pairs naturally with any backend language page. | [SQLBolt (interactive)](https://sqlbolt.com/) · [Mode SQL Tutorial](https://mode.com/sql-tutorial/) |
| 11 | **PHP** | Server-Side / Web | Runs on the web server to generate HTML dynamically before the page reaches the browser. Handles forms, sessions, database calls. | WordPress (≈ 43 % of the web), Facebook's original codebase, Laravel backends, e-commerce (Magento, WooCommerce). | Show a tiny PHP snippet that reads a form field and echoes a personalised greeting, alongside the HTML the server actually sends. | Created by Rasmus Lerdorf, 1994. Often mocked online but **powers a huge share of the live web.** Important for students to know it exists and isn't "dead." | [php.net Manual](https://www.php.net/manual/en/) · [Laravel Docs](https://laravel.com/docs) |
| 12 | **Ruby** | General-Purpose / Web | Emphasises programmer happiness and readable code. The framework Ruby on Rails made rapid web startups possible. | Web apps (GitHub, Shopify, Airbnb early days), automation scripts, prototyping. | A 3-line "Rails-style" snippet: `User.where(active: true).order(:name)` — show how it reads almost like a sentence. | Created by Yukihiro "Matz" Matsumoto, Japan, 1995. Philosophy: "a language designed for programmer happiness." Smaller job market than JS/Python but great for teaching web MVC concepts. | [Try Ruby (interactive)](https://try.ruby-lang.org/) · [Rails Guides](https://guides.rubyonrails.org/) |
| 13 | **Swift** | General-Purpose / Mobile | Apple's modern language for building apps on iPhone, iPad, Mac, Apple Watch, and Apple TV. | iOS / macOS / watchOS / tvOS apps. Server-side Swift (Vapor). Replaced Objective-C as the default Apple language. | A short SwiftUI snippet that renders "Hello, [name]!" with a tap button that increments a counter. Show the *preview canvas* side-by-side with the code. | Created by Chris Lattner at Apple, released 2014. Open-sourced 2015. If your students own iPhones or want to build mobile apps, this is the gateway. | [Apple Swift Book (free)](https://docs.swift.org/swift-book/) · [Swift Playgrounds (iPad app)](https://apps.apple.com/us/app/swift-playgrounds/id908519498) |
| 14 | **Kotlin** | General-Purpose / Mobile | Google's preferred language for Android development. Interoperates with Java but is more concise and safer (null-safety built in). | Android apps (now the official recommendation), server backends, multiplatform (web, desktop, mobile). | Compare a 12-line Java "data class" with the 1-line Kotlin equivalent. Very tangible "fewer keystrokes" demo. | Created by JetBrains (makers of IntelliJ), 2011; Google endorsed it for Android in 2017. Best shown as "Java's modern sibling." | [Kotlinlang.org Docs](https://kotlinlang.org/docs/home.html) · [Android Developers – Kotlin Pathway](https://developer.android.com/courses/pathways/kotlin) |
| 15 | **Scratch** | Visual / Block-Based | You snap coloured blocks together (loops, ifs, variables) to make animations and mini-games. No typing syntax. | Elementary / middle-school CS introductions. Teaching logic before text-based code. | Embed the actual Scratch editor (it runs in-browser via iframe) with a pre-loaded 20-block project. Students can remix it. | Created at MIT Media Lab (Mitchel Resnick), 2007, building on Logo and Squeak. **Perfect "page 0"** for your site if you want a gentle on-ramp before HTML/Python. | [scratch.mit.edu](https://scratch.mit.edu/) · [Scratch Educator Guide](https://en.scratch-wiki.info/wiki/Scratch_Educator_Guide) |
| 16 | **R** | Statistical / Data | Built by statisticians, for statisticians. Dominates academic research, bioinformatics, and data visualisation. | University research papers, public-health dashboards, financial modelling, data journalism. | Load a tiny CSV (e.g., 20 rows of local weather data) and run 3 lines to produce a `ggplot2` scatter chart that updates as you change a parameter. | Created by Ross Ihaka and Robert Gentleman, University of Auckland, 1993. Niche but **extremely relevant if your students take AP/IB Statistics.** | [R for Data Science (free book)](https://r4ds.had.co.nz/) · [Posit (formerly RStudio) Docs](https://posit.co/docs/) |
| 17 | **MATLAB / Julia** | Numerical / Scientific | MATLAB: matrix maths for engineers and physicists. Julia: newer, faster, open-source rival gaining traction. | Control systems, signal processing, computational physics, finance modelling, university STEM labs. | A short script that plots a damped sine wave (vibration) or solves a 3×3 system of equations. Connects coding to what they see in physics / calculus class. | MATLAB: Cleve Moler, 1970s; commercial via MathWorks. Julia: Jeff Bezanson et al., MIT, 2012. Mention that many engineering majors will hit these in college. | [MATLAB Onramp (free)](https://matlabacademy.mathworks.com/) · [Julialang.org](https://julialang.org/) |
| 18 | **Rust** | Systems / General | A memory-safe systems language that gives you C/C++ speed *without* the classic pointer bugs. The compiler is famously strict (and helpful). | Operating-system components (Linux kernel modules, Windows internals), browsers (parts of Firefox/Servo), WebAssembly, embedded. | Show the same small program in C (with a potential buffer-overflow comment) vs. Rust (compiler refuses to build it until fixed). Dramatic and memorable. | Created by Graydon Hoare at Mozilla, first stable release 2015. Voted "most admired language" on Stack Overflow for 8+ years running. Best as an "advanced / future careers" page. | [The Rust Book (free, online)](https://doc.rust-lang.org/book/) · [Rust Playground](https://play.rust-lang.org/) |
| 19 | **Go (Golang)** | General-Purpose / Systems | Built by Google for simplicity and speed in large-scale networked services. No classes, no inheritance, just functions and goroutines. | Cloud infrastructure (Docker, Kubernetes, Terraform), APIs, microservices, CLI tools. | A 20-line web server that returns "Hello, [name]!" — emphasise how few lines it takes. Pair with a Docker/Kubernetes mention. | Created at Google by Rob Pike, Ken Thompson (Unix co-creator), and Robert Griesemer, 2009. Great "what runs the cloud" page. | [Go Tour (interactive)](https://go.dev/tour/) · [Go by Example](https://gobyexample.com/) |
| 20 | **Bash / Shell Scripting** | Scripting / Systems | The language of the terminal. Automates file operations, runs programs in sequence, glues tools together on Linux/macOS. | Server administration, build pipelines (CI/CD), DevOps, data cleaning on Linux. | A 6-line script that renames a folder of images by date. Show the terminal before/after. Students recognise the "black screen" from tech-support memes. | Originates from
