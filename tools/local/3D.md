# 3D Tech Demo — "Orbital Playground" (three.js) — Build Plan

## Goal
A small, self-contained, interactive 3D demo in the browser: a glowing sun with
planets orbiting it, a starfield, orbit-camera, click-to-inspect planets, and a
control panel. Static files only — no build step, no npm install, no framework.
Lives at `tools/local/3d/` and is served like the sibling projects (`/local/3d/`).

Target: 4 short milestones, each one bounded agent run (~10–20 min), total well
under two hours. Everything is procedural — **no models, textures, or media to
download**. The only external resource is three.js itself, vendored once in M0.

## M0 — Skeleton + vendored three.js (deliverable: spinning cube)

**Deliverable:** `http://localhost:8000/3d/` shows a dark page with one slowly
rotating wireframe cube that fills the viewport and follows window resize.

### Steps
1. Create `tools/local/3d/` with `css/`, `js/`, `test/`, `vendor/three/addons/controls/`, `vendor/three/addons/libs/`.
2. Fetch three.js **0.186.0** (pinned; do not use "latest"):
   ```bash
   cd tools/local/3d/vendor/three
   B=https://cdn.jsdelivr.net/npm/three@0.186.0
   curl -fsSL -o three.module.js "$B/build/three.module.js"
   curl -fsSL -o three.core.js   "$B/build/three.core.js"
   curl -fsSL -o addons/controls/OrbitControls.js "$B/examples/jsm/controls/OrbitControls.js"
   curl -fsSL -o addons/libs/lil-gui.module.min.js "$B/examples/jsm/libs/lil-gui.module.min.js"
   ```
   Expected sizes: `three.module.js` ≈130 KB, `three.core.js` ≈1.4 MB,
   `OrbitControls.js` ≈9 KB, `lil-gui` ≈30 KB. If any file is under 1 KB the
   download failed — retry, do not continue.
3. `package.json`: `{ "name": "3d", "private": true, "type": "module" }`
4. `index.html`:
   - `<meta name="viewport" ...>`, `<link rel="stylesheet" href="css/style.css">`
   - `<div id="hud"></div>` (empty for now) and `<canvas id="view"></canvas>`
   - importmap **before** the module script:
     ```html
     <script type="importmap">
     { "imports": {
         "three": "./vendor/three/three.module.js",
         "three/addons/": "./vendor/three/addons/"
     } }
     </script>
     <script type="module" src="js/main.js"></script>
     ```
5. `css/style.css`: `html,body{margin:0;height:100%;background:#05060a;overflow:hidden}`
   `canvas{display:block;width:100%;height:100%}` and a placeholder `#hud` style
   (fixed, top-left, monospace, semi-transparent dark panel, `pointer-events:none`).
6. `js/main.js`:
   - `import * as THREE from 'three'` and `OrbitControls` from `'three/addons/controls/OrbitControls.js'`.
   - `WebGLRenderer({canvas, antialias:true})`, `setPixelRatio(Math.min(devicePixelRatio, 2))`.
   - `PerspectiveCamera(60, aspect, 0.1, 2000)` at `(0, 20, 40)` looking at origin.
   - `OrbitControls` with `enableDamping = true`.
   - Add a `BoxGeometry(4,4,4)` + `MeshBasicMaterial({wireframe:true})` cube.
   - `resize()` on `window` `resize` event: update renderer size + camera aspect.
   - `requestAnimationFrame` loop: rotate cube, `controls.update()`, render.
   - Export nothing; guard with `if (document.getElementById('view'))`.

### Headless checks (agent runs)
```bash

ls -l vendor/three vendor/three/addons/controls vendor/three/addons/libs   # sizes as above
grep -c "three.core.js" vendor/three/three.module.js                        # must be >= 1

done
pkill -f "http.server 8010"
```
Definition of done: every curl returns `200`, `node --check` is silent, sizes match.

**Visual check (owner):** spinning wireframe cube, drag orbits, scroll zooms,
console clean. Resize the window — canvas follows.

## M1 — Orbital math in pure JS + unit tests (deliverable: `sim.js` green)

**Deliverable:** `js/sim.js` exports planet data and position math with no
three.js dependency; `node --test` passes.

### Steps
1. `js/sim.js` exports:
   - `PLANETS`: array of 6 objects `{ name, radius, orbit, period, color, tilt }`.
     Use readable made-up values, e.g. radius 0.6–2.2, orbit 6–34 (spacing ≥ 4),
     period 4–60 s, color as hex number, tilt in radians (0–0.4). Give each a
     distinct pleasant color; names can be invented (e.g. "Ember", "Cobalt").
   - `orbitAngle(planet, tSeconds)` → `(2π · t / planet.period) % 2π`.
   - `planetPosition(planet, tSeconds)` → `{x, y, z}` on a circle of radius
     `orbit` in the XZ plane, then rotated about X by `tilt`
     (`y = z·sin(tilt)`, `z = z·cos(tilt)`).
   - `createClock()` → `{ t, speed, paused, advance(dtSeconds) }` where
     `advance` adds `dt · speed` to `t` unless paused. Default speed 1.
   - `describe(planet)` → short multi-line string for the HUD
     (name, orbit radius, period, radius).
2. `test/sim.test.mjs` using `node:test` + `node:assert/strict`:
   - `PLANETS` has 6 entries, orbits strictly increasing, all periods > 0.
   - `orbitAngle` at `t = period` ≈ 0 and at `t = period/4` ≈ π/2 (tolerance 1e-9).
   - `planetPosition` at `t = 0` is `(orbit, 0, 0)`; distance from origin equals
     `orbit` for several `t` (tilt preserves radius).
   - `createClock`: `advance(1)` → `t = 1`; `speed = 3; advance(1)` → `t = 4`;
     `paused = true; advance(5)` → still `4`.
   - `describe` includes the planet's name.

### Headless checks
```bash
cd tools/local/3d
node --test test/            # all tests pass, 0 failures
grep -n "from 'three'" js/sim.js && echo "FAIL: sim.js must not import three" || echo "ok: sim is pure"
```
Definition of done: `node --test` reports 0 fail; sim.js has no three import.

## M2 — The scene: sun, planets, rings, starfield (deliverable: living solar system)

**Deliverable:** Replace the cube. A glowing sun lights 6 orbiting planets on
faint orbit rings against a starfield; camera orbits with damping.

### Steps
1. `js/scene.js` exporting `buildScene(THREE)` → `{ scene, sun, planets, rings, stars }`
   (pass `THREE` in, or import it — either is fine; keep it consistent).
   - `scene.background = new THREE.Color(0x05060a)`.
   - Sun: `SphereGeometry(3, 48, 48)` + `MeshBasicMaterial({color:0xffc857})`
     plus a `PointLight(0xffe0b0, 800, 0, 1.6)` at origin and a dim
     `AmbientLight(0x223344, 0.6)`. (three r155+ uses physical light units —
     if the scene looks black, raise intensity ×10 rather than changing decay.)
   - Planets: for each `PLANETS[i]`, `SphereGeometry(radius, 32, 32)` +
     `MeshStandardMaterial({color, roughness:0.7, metalness:0.1})`.
     Store `mesh.userData.planet = planet` and `mesh.name = planet.name`.
   - Rings: for each planet, a `RingGeometry(orbit-0.03, orbit+0.03, 128)` with
     `MeshBasicMaterial({color:0x3a4b6a, side:DoubleSide, transparent:true, opacity:0.5})`,
     rotated `-π/2` about X, then `rotation.x += tilt` so it lies on the tilted orbit.
   - Stars: `BufferGeometry` with 3000 random points in a shell of radius
     300–600 (`Float32Array`, `setAttribute('position', ...)`), rendered with
     `PointsMaterial({size:1.2, sizeAttenuation:true, color:0xdde6ff})`.
   - Group planets under one `Group` named `"planets"` so later code can find them.
2. `js/main.js`:
   - Import `buildScene`, `createClock`, `planetPosition`.
   - Remove the cube. Each frame: `dt` from `THREE.Clock`, `clock.advance(dt)`,
     then for each planet mesh set `position` from `planetPosition(planet, clock.t)`
     and spin it slowly on Y (`rotation.y += dt * 0.5`).
   - Slowly pulse the sun scale `1 + 0.02·sin(t·2)`.
   - Keep resize + OrbitControls from M0. `controls.maxDistance = 200`.
   - Export nothing new; keep `clock`, `scene`, `camera`, `renderer` in module scope
     and expose them for the next milestone via
     `export const app = { clock, scene, camera, renderer, controls }`.

### Headless checks
```bash
cd tools/local/3d
node --check js/main.js && node --check js/scene.js
node --test test/                                   # still green
grep -c "PLANETS" js/scene.js                       # >= 1
grep -n "BoxGeometry" js/main.js && echo "FAIL: cube still present" || echo "ok: cube removed"
```
Definition of done: syntax clean, tests green, cube gone, scene.js uses PLANETS.

**Visual check (owner):** sun glows, 6 planets orbit at different speeds on
tilted rings, stars all around, drag/zoom works, ~60 fps, console clean.

## M3 — Interaction: click-to-inspect, control panel, keyboard (deliverable: it's a demo)

**Deliverable:** Click a planet → it highlights and the HUD shows its details;
a lil-gui panel controls speed / pause / orbits / wireframe / follow; keyboard
shortcuts; a `?` help overlay.

### Steps
1. `js/pick.js` exporting `setupPicking({ renderer, camera, planetsGroup, onSelect })`:
   - `Raycaster` + pointer `Vector2`; on `pointerdown` record position, on
     `pointerup` only fire if the pointer moved < 5 px (so orbit-drags don't select).
   - `raycaster.intersectObjects(planetsGroup.children, false)`; first hit wins.
   - Highlight: set `material.emissive` to the planet color × 0.5 on the selected
     mesh, restore `0x000000` on the previous one. Click empty space → deselect.
   - Call `onSelect(meshOrNull)`.
2. `js/ui.js` exporting `setupUI({ app, planetsGroup, rings, hud })`:
   - `import { GUI } from 'three/addons/libs/lil-gui.module.min.js'` (named export — there is NO default export).
   - Panel (title "Orbital Playground"):
     `speed` slider 0–10 (binds `app.clock.speed`), `paused` checkbox,
     `orbits` checkbox (toggles each ring's `visible`), `wireframe` checkbox
     (sets `wireframe` on every planet material), `follow` checkbox (when on and
     a planet is selected, `controls.target.copy(mesh.position)` every frame),
     `resetCamera` button (camera back to `(0,20,40)`, target origin).
   - HUD: default text "Click a planet · drag to orbit · scroll to zoom · ? for help";
     on select, show `describe(planet)`.
   - Keyboard: `Space` toggles pause, `R` resets camera, `Esc` deselects,
     `?` toggles the help overlay, `1`–`6` selects planet by index.
   - Help overlay: `<div id="help" hidden>` in `index.html` listing the controls;
     toggle with `el.hidden = !el.hidden`.
3. Wire it in `js/main.js`: after building the scene call `setupPicking` and
   `setupUI`; keep the follow-behaviour in the frame loop (before `controls.update()`).
4. `css/style.css`: style `#hud` and `#help` as dark glass panels
   (`background:rgba(10,12,20,.75); backdrop-filter:blur(6px); border:1px solid #2a3350; border-radius:8px; padding:10px 14px; color:#dbe4ff; font:13px/1.4 ui-monospace,monospace`).
   `#hud` top-left, `#help` centered. lil-gui goes top-right by default — leave it.

### Headless checks
```bash

node --test test/
grep -c "Raycaster" js/pick.js                       # >= 1

```
Definition of done: all checks pass; every listed control and key is implemented.

**Visual check (owner):** click planet → glows + HUD updates; drag does not
select; sliders/checkboxes work live; Space pauses; `?` shows help; `follow`
keeps a selected planet centered; console clean.

## Scope guard — things that are deliberately NOT in this demo
- No GLTF/OBJ model loading, no texture downloads, no HDR environment maps.
- No post-processing (bloom etc.) — the emissive sun is enough.
- No physics engine, no collisions, no audio.
- No mobile-specific layout (touch orbit/zoom works via OrbitControls already).
- No build tooling. If the agent proposes `npm install` or Vite, decline.

If any of these feels tempting, it belongs in a follow-up plan, not here.
