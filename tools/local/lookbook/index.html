HTML CSS Basics Layout Components

What is HTML?

HTML (HyperText Markup Language) gives your page structure. It doesn't make things look nice — that's CSS's job. Think of HTML as the skeleton and CSS as the skin, clothes, and makeup.

Headings

<h1> through <h6> define heading levels. Use them to create a clear hierarchy — one <h1> per page, then nest down from there.

Paragraphs & Text

<p> wraps blocks of text. For emphasis use <strong> (bold) and <em> (italic). Avoid <b> and <i> — they carry no meaning.

Links

<a href="..."> creates a hyperlink. Always give it descriptive text — "click here" tells the reader nothing.

Lists

<ul> for unordered (bulleted) lists, <ol> for ordered (numbered). Each item goes in an <li>.

CSS Basics

CSS (Cascading Style Sheets) tells the browser how to paint your HTML. A rule has a selector and a declaration block:

Selectors

Target elements by tag (p), class (.intro), or id (#header). Classes are reusable; ids should be unique on a page.

Properties & Values

Inside the braces you write declarations: color: blue;, font-size: 16px;. Each ends with a semicolon.

Units

px is fixed. rem scales with the root font size (great for accessibility). % is relative to the parent element.

The Box Model

Every element is a box: content → padding → border → margin. Understanding this is the single most important thing in CSS.

Layout

CSS layout tools let you arrange elements on the page. Here are the three most important ones:

Flexbox

One-dimensional layout. Great for nav bars, button rows, and centering things. Set display: flex; on the parent.

Grid

Two-dimensional layout. Define rows and columns with grid-template-columns. Perfect for card grids like this one.

Responsive Design

Use media queries (@media (max-width: 640px)) to change styles at different screen sizes. Your page should work on phones and desktops.

Components

A component is a reusable piece of UI — a button, card, or form field. CSS lets you style them however you want.

"HTML is the structure. CSS is the presentation. JavaScript is the behavior. Learn them in that order — each one builds on the last." — A common piece of advice for beginners
